**구간** Phase 3 (2026.06.08) | **포지션** 툴 | **AI** 협업

- **문제**: Steam Idle 장르 시장을 분석하려면 데이터가 필요하다. 그런데 Steam 전체 카탈로그를 크롤링하는 것은 비현실적이고, 기존 공개 프로젝트를 참고하려 했다.
- **해결**: 두 가지 판단이 이 카드를 만든다.
  - **크롤링 없이 카탈로그 확보** — SteamSpy의 **태그 엔드포인트**를 이용하면 장르별 게임 목록을 전수 크롤링 없이 가져올 수 있다는 것을 찾아냈다.
  - **참고 프로젝트가 목업임을 규명** — 참고하려던 공개 프로젝트가 실제로는 **FNV-1a 해시로 생성한 가짜 데이터**를 쓰고 있다는 것을 코드 분석으로 밝혀냈다. 그럴듯한 숫자가 나오지만 실데이터가 아니다. 이를 확인하고 **실데이터 기반으로 재설계**했다.
  - 분석 파이프라인에는 **가중평균 + MAD(중앙값 절대편차) 이상치 제거**를 넣고, 결과를 정적 대시보드로 냈다.
- **기술**: SteamSpy API 태그 엔드포인트, 데이터 파이프라인(가중평균·MAD 이상치 제거), 정적 대시보드 생성, 서드파티 코드 검증
- **정량**: 전수 크롤링 회피 / MAD 이상치 제거 파이프라인 / 정적 대시보드
