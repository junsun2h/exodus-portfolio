# F-20. 동시성/멱등성 버그 3종 해결

> **코드 발췌 없음.** 이 항목은 전역 정책 변경·조사·설계 문서 형태의 작업이라
> 특정 파일로 잘라낼 수 없다. 아래 카드의 *근거* 항목이 실제 산출물이다.

**구간** Phase 2 (2026.01.07 ~ 01.13) | **포지션** 서버 | **AI** 협업

- **문제**: 서버가 정상 동작하는 것처럼 보이는데, **특정 타이밍에서만** 결과가 어긋나는 버그 3종이 발생했다. 재현이 어렵고 로그로는 잡히지 않는 부류다.
- **해결**: 세 건 모두 근본 원인을 규명해 명세서로 남겼다.

| 버그 | 증상 | 근본 원인 |
|---|---|---|
| **가챠 해시 불일치** | 가챠를 연속으로 빠르게 클릭하면 클라 예측(F-07)과 서버 결과가 어긋남 | 요청 간 해시 시퀀스 동기화 실패 |
| **Stage RandomHash 동기화** | 스테이지 보상 랜덤 결과가 클라·서버 간 불일치 | 스테이지 진행 중 해시 상태 동기화 누락 |
| **`Promise.all` 공유 인스턴스 배열 오염** | 병렬 처리 시 결과가 뒤섞임 | `Promise.all`로 병렬 실행되는 작업들이 **같은 인스턴스 배열을 공유**해 서로의 상태를 덮어씀 |

- **기술**: 결정론 PRNG 시퀀스 동기화, JS 비동기 병렬 실행의 공유 상태 격리, 멱등성 보장
- **정량**: 근본원인 명세서 **3종**
