# 밸런싱 분석 에이전트

배틀 시뮬레이터 리포트를 자동으로 분석하고 밸런스 조정 제안을 생성합니다.

## 밸런싱 목표

### 공격력 성장 중심 비대칭 밸런스 (Attack-Focused Asymmetric Balance)

**핵심 철학**:
> "DPS를 올리는 것이 재미있고 강해지는 체감이 됨. 죽는 것을 방지하는 것은 숙제처럼 느껴짐."

**설계 의도**:
- 유저가 **공격력 성장**에 집중하도록 유도
- 생존은 여유있게 설정하여 **방어 콘텐츠는 보조적 역할**
- 주요 실패 유형: **타임오버** (죽음보다 심리적 부담 적음)

| 방향 | 목표 | 이상적 범위 | 밸런스 철학 |
|------|------|------------|------------|
| 플레이어 → 몬스터 | **55초** | 50~60초 | 핵심 성장 지표, DPS 체크 |
| 몬스터 → 플레이어 | **70초** | 65~80초 | 여유있게 설정, 생존은 보조 |

### 왜 타임오버 중심인가? (UX 분석 결과)

**방치형 게임 특성 고려**:
- 실패 시 -1 스테이지로 이동 → 자동 안정화
- 오프라인 보상으로 성장 지속 (최대 24시간, 1분/1클리어)
- 두 실패 유형의 실질적 손해는 동일

**심리적 차이만 존재**:
| 실패 유형 | 유저 심리 | 성장 방향 유도 |
|-----------|-----------|----------------|
| **죽음** | "죽었다" → 좌절감 높음 | 방어/힐/HP 콘텐츠 |
| **타임오버** | "시간 부족" → 아쉬움 | 공격/DPS 콘텐츠 ✅ |

**결론**: 타임오버가 주요 실패 유형이 되도록 생존 시간을 여유있게 설정

### ⚠️ 중요: 저항 적용 후 기준 평가
**생존 시간 계산은 반드시 플레이어 저항 적용 후 "최종 DPS" 기준으로 평가해야 합니다.**

```
❌ 잘못된 평가 (Raw DPS 기준)
   목표 DPS = 플레이어 HP / 70초
   → Raw DPS만 맞추면 저항에 의해 실제 생존 시간이 크게 늘어남

✅ 올바른 평가 (최종 DPS 기준)
   목표 최종 DPS = 플레이어 HP / 70초
   필요 Raw DPS = 목표 최종 DPS / (1 - 평균저항)
   → 저항 적용 후 실제로 70초 생존이 되도록 Raw DPS를 역산
```

**계산 예시** (평균 저항 49.4% 기준):
| 항목 | 계산식 | 값 |
|------|--------|-----|
| 플레이어 HP | - | 11.03T |
| 목표 최종 DPS | HP / 70초 | 157.57B |
| 필요 Raw DPS | 최종 DPS / (1 - 0.494) | **311.4B** |

### 허용 범위
- **처치 시간 목표**: 55초 (허용 범위: 50~60초)
- **생존 시간 목표**: 70초 (허용 범위: 65~80초)
- **위험 판정**:
  - ❌ 처치 60초 초과 → 시간 초과 실패 위험
  - ⚠️ 처치 50초 미만 → 너무 빠름 (버프로 더 빠르게만 가능)
  - ⚠️ 생존 50초 미만 → 죽음 실패 빈도 증가 (의도와 다름)
  - ✅ 생존 65~80초 → 정상 (타임오버 중심 유지)
  - ✅ 생존 80초 초과 → 긴장감 부족 주의

## 공식 참고

### POLY 공식 (몬스터 HP/DPS)
```
f(x) = Start + Multiplier × (x-1)^ExpBase
Multiplier = (목표값 - Start) / (999^ExpBase)
```

### EXP1/LINEAR 공식
```
f(x) = Start + (Multiplier × x)
```

### EXP3 공식 (스킬 피해 %)
```
f(x) = Multiplier × ExpBase^x × 0.0001
(x = 스킬 레벨)

예시: skillspell_icelance (Lv65)
- Multiplier: 102.94
- ExpBase: 1.02
- f(65) = 102.94 × 1.02^65 × 0.0001
       = 102.94 × 3.632 × 0.0001
       = 0.0374 (3.74%)
```

### 적정값 계산 공식
```
적정 계층 보스 Life = 플레이어 DPS × 목표 처치 시간(55초)
적정 최종 DPS = 플레이어 HP / 목표 생존 시간(70초)
적정 Raw DPS = 적정 최종 DPS / (1 - 평균저항)
```

### 배율 적용 계산
```
계층 보스 실제 값 = 기본값 × 1000%
일반 보스 실제 값 = 기본값 × 500%
일반 몬스터 실제 값 = 기본값 × 100%
```
