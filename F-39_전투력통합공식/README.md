# F-39. 전투력(CombatPower) 통합 공식 재설계

> 소스 발췌: `src/` — 1개 파일

**구간** Phase 3 (2026.04.10 ~ 04.15) | **포지션** TD | **AI** 협업

- **문제**: 전투력 수치가 콘텐츠마다 제각각 계산되고 있었다. 장비·스킬·펫·룬·성좌가 각자 다른 방식으로 전투력에 기여해, **콘텐츠 간 비교가 불가능**하고 유저에게도 일관된 성장 지표를 줄 수 없었다.
- **해결**: **전 콘텐츠 통합 공식**을 설계했다.

  `tier × gradeMult × (BASE + reinforce × SCALE + Σ(modTier) × SCALE)`

  - **비선형 등급 가속** — 등급이 오를수록 기여가 가속되도록 `gradeMult`를 비선형으로 설계. 상위 등급의 가치를 수치로 표현한다.
  - **비순차 enum 정규화** — 등급 열거형이 `grade0 = 10`, `grade5 = 11`처럼 **선언 순서와 값이 일치하지 않는** 상태였다. enum 값을 그대로 계수로 쓰면 계산이 완전히 어긋난다. 이를 정규화하고 **위키로 문서화**해 재발을 막았다.
  - 단계적으로 진행했다: 시스템 설계(04.10) → MOD 개별 Coefficient 반영(04.11) → 팩터 스케일 재조정(04.11) → 전 콘텐츠 통합 재설계(04.14~15).
- **기술**: 통합 스코어 공식 설계, 비선형 등급 계수, 열거형 값 정규화, 콘텐츠별 기여도 스케일 조정
- **정량**: 전 콘텐츠 일괄 적용 / 설계 문서 4종 + 위키 2종

- **면접 포인트**: **"비순차 enum을 발견하고 위키로 남긴 것"**이 이 카드의 숨은 요점이다. `grade0 = 10, grade5 = 11` 같은 함정은 한 번 고쳐도 다음 사람(또는 6개월 뒤의 나, 또는 AI)이 다시 밟는다. 그래서 **주의사항 위키**를 별도로 만들었다. 전투력처럼 모든 콘텐츠가 참조하는 지표를 단일 공식으로 통합한 것은 게임 시스템 설계 역량을, 함정을 문서화한 것은 TD 역량을 각각 보여준다.
