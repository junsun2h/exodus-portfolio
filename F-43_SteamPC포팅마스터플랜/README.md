**구간** Phase 3 (2026.06.07) | **포지션** TD | **AI** 협업 (적대적 교차검증)

- **문제**: 모바일 방치형으로 만든 게임을 Steam PC로 포팅할 수 있는가? 이 게임은 **Firebase에 깊게 결합**되어 있다 — 서버 권위 구조 전체가 Cloud Functions 위에 있다. Steam은 그런 백엔드를 전제하지 않는다. 감으로 "가능할 것 같다"고 판단하면 수백 일을 날릴 수 있다.
- **해결**: **16개 영역을 전수 조사**해 결합 규모를 수치로 확정하고, 3단계 검증을 거쳐 WBS를 만들었다.

| 조사 결과 | 수치 |
|---|---|
| Firebase 클라 매니저 | 5개 **2,581줄** |
| GameAPI 매니저 | 29개 **10,858줄** |
| 서버 호출 지점 | **103지점 / 57파일** |
| 대체 필요 서버 함수 | **139개** → 로컬 디스패치 전환 설계 |

  **검증 방식이 이 카드의 핵심이다.**
  1. **1차 조사** — 16개 영역 전수 파악
  2. **2차 적대적 교차검증** — 1차 결과를 **반박하는 관점**으로 재검증. 낙관 편향을 제거한다.
  3. **WBS 3점 추정** — 낙관 **450일** / 최빈 **705일** / 비관 **1,074일**

- **기술**: 대규모 의존성 전수 조사, 적대적 교차검증 방법론, PERT 3점 추정, 서버 함수 → 로컬 디스패치 전환 설계
- **정량**: 16개 영역 / 서버 호출 103지점 57파일 / 서버함수 139개 / **3점 추정 450·705·1,074일**
