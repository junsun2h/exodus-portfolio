# F-14. 전 빌드 순회 자동 분석

> 소스 발췌: `src/` — 3개 파일
>
> 배틀 시뮬레이터(F-13) 내부 모듈. **실행 리포트 2종**이 함께 있어 10개 아키타입 순회 결과를 그대로 볼 수 있다.

**구간** Phase 2 (2025.11.18) | **포지션** 툴 | **AI** 협업

- **문제**: 시뮬레이터(F-13)로 개별 빌드 DPS는 볼 수 있게 됐지만, **"어떤 빌드가 유리한가"는 사람이 하나씩 돌려봐야** 했다. 5속성 × 2전달방식 = 10개 아키타입에 각각 최적 장비·스킬 조합이 있으니 조합 수가 폭발한다.
- **해결**: **10개 아키타입을 자동 순회**하며, 각 빌드마다 최적 장비/스킬을 자동 선택한 뒤 평균 기여도를 산출하는 파이프라인을 만들었다. 밸런스 수치를 바꾸면 전 빌드 결과가 한 번에 갱신된다.
- **기술**: 아키타입 조합 자동 생성, 빌드별 최적화 탐색 + 기여도 집계, 시뮬레이터 배치 실행
- **정량**: 아키타입 **10종**(5속성 × 2전달방식) 자동 순회
- **근거**: `Docs/배틀/MOD밸런스/2. 모든 빌드 순회 분석/25.11.18_모든빌드순회분석_TODO.md`
- **면접 포인트**: **밸런싱을 "감"에서 "전수 측정"으로 옮긴 지점.** 특정 빌드만 강한지 여부를 주관이 아니라 10개 아키타입 전수 결과로 판정한다. 이후 표준 빌드 정의(`3. 표준 빌드 만들기`), MOD 가중치 분석(`4. 표준모드분석`)이 이 파이프라인 위에 쌓인다.
- **슬라이드 자료**: 10개 아키타입 기여도 비교 리포트 — **캡처 필요**
