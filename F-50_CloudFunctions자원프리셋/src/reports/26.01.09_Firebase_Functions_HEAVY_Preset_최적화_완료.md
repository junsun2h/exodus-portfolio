## Part 2: 클라이언트 PRNG 동기화

### 배경
서버 Phase 3 최적화에서 `reward_pay_perkill`의 PRNG 호출 횟수가 변경됨:
- **Before**: `numMonsters`회 PRNG 호출 (최대 100,000회)
- **After**: 2회 PRNG 호출 + 이항 분포 샘플링

클라이언트와 서버가 동일한 Hash 시드로 PRNG을 사용하므로, 호출 횟수 불일치 시 이후 모든 랜덤 결과가 어긋남.

### 수정된 클라이언트 파일

| 파일 | 수정 내용 | 상태 |
|------|----------|------|
| `Assets/Source/Utility/GameUtility.cs` | `SampleBinomial()` 함수 추가 | ✅ 완료 |
| `Assets/Source/Logic/ClientGacha/ClientStageReward.cs` | `CreateStageRewardParameter()` 수정 | ✅ 완료 |

### 구현 내용

#### GameUtility.SampleBinomial (C#)
```csharp
public static int SampleBinomial(int n, double p, float rand1, float rand2)
{
    if (n <= 0 || p <= 0) return 0;
    if (p >= 1) return n;

    double mean = n * p;
    double stdDev = System.Math.Sqrt(n * p * (1 - p));

    // n이 충분히 크면 정규 근사 (Box-Muller 변환)
    if (n >= 20 && mean >= 5 && n * (1 - p) >= 5)
    {
        double u1 = System.Math.Max(rand1, 1e-10);
        double u2 = rand2;
        double z = System.Math.Sqrt(-2 * System.Math.Log(u1)) * System.Math.Cos(2 * System.Math.PI * u2);
        int result = (int)System.Math.Round(mean + z * stdDev);
        return System.Math.Max(0, System.Math.Min(n, result));
    }

    // n이 작으면 역변환 샘플링
    int successes = 0;
    double cumulativeProb = 0;
    double q = 1 - p;
    double prob = System.Math.Pow(q, n);

    for (int k = 0; k <= n; k++)
    {
        cumulativeProb += prob;
        if (rand1 <= cumulativeProb)
        {
            successes = k;
            break;
        }
        prob *= (n - k) / (double)(k + 1) * (p / q);
    }

    return successes;
}
```

## 핵심 알고리즘 설명

### 이항 분포 샘플링
- **목적**: N회 독립 시행의 성공 횟수를 2회 PRNG 호출로 계산
- **방법 1 (n≥20)**: 정규 분포 근사 + Box-Muller 변환
- **방법 2 (n<20)**: 역변환 샘플링 (Inverse Transform Sampling)
- **효과**: 10만 회 PRNG 호출 → 2회로 감소

### 이진 탐색 최적화
- **목적**: 가챠 확률 테이블에서 당첨 등급 결정
- **방법**: 누적 확률 배열 캐싱 + Lower Bound 이진 탐색
- **효과**: O(n) 선형 탐색 → O(log n)
